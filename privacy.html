プライバシーポリシー

制定日: 2026年11月3日

1. このアプリについて

Shorts Uploader（以下「本アプリ」）は、YouTube チャンネル「AI 1分図鑑」の運営者（以下「運営者」）が、 自ら制作した動画を自分のチャンネルにアップロードするためだけに使う個人用ツールです。一般には提供していません。

2. 取得する情報

本アプリは、Google の OAuth 認証により、運営者自身の Google アカウントについて次の権限のみを取得します。

  • https://www.googleapis.com/auth/youtube.upload（YouTube 動画の管理：動画のアップロード）

認証の結果として発行されるアクセストークンとリフレッシュトークンのほかに、個人情報・視聴データ・他のユーザーのデータは取得しません。

3. 利用目的

取得した権限は、運営者が制作した動画を運営者のチャンネルへアップロードし、公開日時を予約する目的にのみ使用します。

4. 保存と管理

トークンは運営者のパソコン内にのみ保存し、外部のサーバーには送信・保存しません。

5. 第三者への提供

Google API から取得した情報を第三者に販売・提供・共有することはありません。広告や AI モデルの学習には使用しません。

6. Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から受け取った情報の使用および他のアプリへの転送は、 Google API Services User Data Policy （Limited Use の要件を含む）に従います。

7. アクセス権の取り消し

本アプリへのアクセス権は、Google アカウントの「サードパーティ製のアプリとサービス」 からいつでも取り消せます。取り消すと、保存されたトークンは使用できなくなります。

Privacy Policy

Effective date: November 3, 2026

1. About this app

Shorts Uploader ("the App") is a personal tool used only by the operator of the YouTube channel "AI 1分図鑑" ("the Operator") to upload videos the Operator created to the Operator's own channel. It is not offered to the public.

2. Data accessed

Through Google OAuth, the App requests only the following scope for the Operator's own Google account:

  • https://www.googleapis.com/auth/youtube.upload (upload YouTube videos)

Apart from the access and refresh tokens issued by Google, the App does not collect any personal data, viewing data, or data of any other user.

3. How data is used

The access is used solely to upload the Operator's videos to the Operator's channel and to set their scheduled publish time.

4. Storage

Tokens are stored only on the Operator's own computer and are never sent to or stored on any external server.

5. Sharing

Information received from Google APIs is never sold, shared with, or transferred to third parties, and is not used for advertising or for training AI models.

6. Google API Services User Data Policy

The App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Revoking access

Access can be revoked at any time from Third-party apps & services in your Google Account.
